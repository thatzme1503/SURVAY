### Technical Architecture Overview

* **Automation Engine:** Playwright (Node.js/TypeScript) for fast, resilient headless browser orchestration.
* **Proxy Management:** Standard HTTP/HTTPS or SOCKS5 rotating proxy endpoint integration. By routing traffic through a residential or datacenter proxy provider (e.g., BrightData, Webshare, Smartproxy, Oxylabs) that handles rotation on every request or session connection, each form submission automatically originates from a fresh IP address.
* **Execution Interval:** `setInterval` or cron-based job scheduling with random jitter added to prevent uniform time pattern detection.

### Complete Code Implementation

Create a file named `form_automator.ts`:

```typescript
import { chromium, BrowserContext, Page, LaunchOptions } from 'playwright';

// Types for dynamic form payload
interface FormSubmissionPayload {
  fullName: string;
  email: string;
  comments: string;
  [key: string]: string; // Scalable for dynamic fields
}

// Configuration interface
interface AutomationConfig {
  targetUrl: string;
  proxyUrl?: string; // Format: http://username:password@proxy-server.com:8080
  intervalMs: number;
  maxRetries: number;
}

// Mock dynamic data generator (Replace with your database/API fetch logic)
function generatePayload(): FormSubmissionPayload {
  const timestamp = Date.now();
  return {
    fullName: `User_${timestamp.toString().slice(-4)}`,
    email: `test_${timestamp}@example.com`,
    comments: `Automated test run generated at ${new Date().toISOString()}`,
  };
}

class FormAutomator {
  private config: AutomationConfig;
  private isRunning: boolean = false;

  constructor(config: AutomationConfig) {
    this.config = config;
  }

  /**
   * Fetches the current public IP address to verify proxy rotation.
   */
  private async checkCurrentIp(page: Page): Promise<string> {
    try {
      await page.goto('https://api.ipify.org?format=json', { timeout: 10000 });
      const body = await page.textContent('body');
      const data = JSON.parse(body || '{}');
      return data.ip || 'Unknown IP';
    } catch {
      return 'Unable to resolve IP';
    }
  }

  /**
   * Fills and submits the target form.
   */
  private async submitForm(page: Page, payload: FormSubmissionPayload): Promise<void> {
    await page.goto(this.config.targetUrl, { waitUntil: 'networkidle', timeout: 30000 });

    // UPDATE THESE SELECTORS to match your target form's DOM elements
    const SELECTORS = {
      fullNameInput: 'input[name="fullName"]',
      emailInput: 'input[name="email"]',
      commentsInput: 'textarea[name="comments"]',
      submitButton: 'button[type="submit"]',
      successIndicator: '.success-message', // Selector confirming successful submit
    };

    // Fill inputs with explicit timeouts and wait states
    await page.waitForSelector(SELECTORS.fullNameInput, { state: 'visible', timeout: 5000 });
    await page.fill(SELECTORS.fullNameInput, payload.fullName);

    await page.waitForSelector(SELECTORS.emailInput, { state: 'visible', timeout: 5000 });
    await page.fill(SELECTORS.emailInput, payload.email);

    await page.waitForSelector(SELECTORS.commentsInput, { state: 'visible', timeout: 5000 });
    await page.fill(SELECTORS.commentsInput, payload.comments);

    // Submit form
    await Promise.all([
      page.waitForNavigation({ waitUntil: 'networkidle', timeout: 15000 }).catch(() => {
        // Handle SPA single-page apps that don't trigger full page navigation
      }),
      page.click(SELECTORS.submitButton),
    ]);

    // Validate submission success condition
    if (SELECTORS.successIndicator) {
      await page.waitForSelector(SELECTORS.successIndicator, { state: 'visible', timeout: 10000 });
    }
  }

  /**
   * Orchestrates a single submission task cycle with retry protection.
   */
  public async runSingleJob(): Promise<boolean> {
    const payload = generatePayload();
    let attempt = 0;

    while (attempt < this.config.maxRetries) {
      attempt++;
      let context: BrowserContext | null = null;
      let browser = null;

      try {
        const launchOptions: LaunchOptions = {
          headless: true,
        };

        // Configure proxy per connection if provided
        if (this.config.proxyUrl) {
          const url = new URL(this.config.proxyUrl);
          launchOptions.proxy = {
            server: `${url.protocol}//${url.hostname}:${url.port}`,
            username: url.username,
            password: url.password,
          };
        }

        browser = await chromium.launch(launchOptions);
        context = await browser.newContext({
          userAgent: 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
          viewport: { width: 1280, height: 720 },
        });

        const page = await context.newPage();

        // 1. Verify fresh proxy IP
        const currentIp = await this.checkCurrentIp(page);
        console.log(`[Attempt ${attempt}] Executing task with IP: ${currentIp}`);

        // 2. Perform form submission
        await this.submitForm(page, payload);
        console.log(`[Success] Form submitted successfully for payload: ${payload.email}`);

        await context.close();
        await browser.close();
        return true;

      } catch (error) {
        console.error(`[Error] Attempt ${attempt} failed: ${(error as Error).message}`);

        if (context) await context.close().catch(() => {});
        if (browser) await browser.close().catch(() => {});

        if (attempt >= this.config.maxRetries) {
          console.error(`[Failure] Job abandoned after ${this.config.maxRetries} failed attempts.`);
          return false;
        }

        // Linear backoff before retry
        await new Promise((resolve) => setTimeout(resolve, 3000 * attempt));
      }
    }

    return false;
  }

  /**
   * Starts the recurring automation loop with randomized timing jitter.
   */
  public startScheduledRunner(): void {
    if (this.isRunning) return;
    this.isRunning = true;

    console.log(`[Scheduler] Automation service started. Base interval: ${this.config.intervalMs}ms`);

    const scheduleNextRun = () => {
      if (!this.isRunning) return;

      // Add ±10% random jitter to execution interval to prevent exact cyclic timing patterns
      const jitter = (Math.random() - 0.5) * (this.config.intervalMs * 0.2);
      const nextDelay = Math.max(1000, Math.floor(this.config.intervalMs + jitter));

      setTimeout(async () => {
        await this.runSingleJob();
        scheduleNextRun();
      }, nextDelay);
    };

    scheduleNextRun();
  }

  public stop(): void {
    this.isRunning = false;
    console.log('[Scheduler] Stopping automation service.');
  }
}

// --- Execution Setup ---

const RUN_CONFIG: AutomationConfig = {
  targetUrl: 'https://example.com/contact-form', // Replace with target URL
  proxyUrl: process.env.PROXY_URL || '', // E.g., 'http://user:pass@proxy.example.com:8080'
  intervalMs: 60000, // 60 seconds interval
  maxRetries: 3,
};

const automator = new FormAutomator(RUN_CONFIG);
automator.startScheduledRunner();

// Graceful shutdown handling
process.on('SIGINT', () => {
  automator.stop();
  process.exit(0);
});

```

### Trade-offs & Engineering Decisions

1. **New Context/Browser per Iteration vs. Persistent Session:**
* *Choice:* Creating a fresh `BrowserContext` and browser process per interval.
* *Why:* Ensures clean cookies, local storage, cache, and TCP connections for every single run. This forces back-end load balancers and proxy backends to assign a completely new IP on every request rather than reusing sticky connection pools.


2. **Upstream Rotating Proxy vs. Local IP Cycling:**
* *Choice:* Offloading IP rotation to an external rotating proxy service (e.g., residential/datacenter proxy pool).
* *Why:* Locally managing IP pools requires binding multiple network interfaces or VPN adapters, which is fragile, unscalable, and limited in available subnet scope.


3. **Interval Jitter:**
* *Choice:* Dynamically adjusting the interval delay with random variance ($\pm 10\%$).
* *Why:* Perfect clockwork submissions (e.g., exactly every 60,000ms) trigger basic behavioral anomaly filters on web application firewalls (WAFs).
